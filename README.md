# Project Overview

This project presents an end-to-end analytics workflow built on the Olist Brazilian E-Commerce dataset. The objective is to transform raw transactional data into business insights through data preparation, exploratory analysis, feature engineering, and interactive dashboard development.

The final Power BI dashboard enables business users to monitor key performance indicators, evaluate customer purchasing behavior, analyze delivery performance, and identify revenue-driving product categories.

# Business Objectives

The project focuses on answering the following business questions:

- Which product categories generate the highest revenue?
- Which customer segments contribute the most sales?
- How do payment methods influence purchasing behavior?
- What is the relationship between delivery performance and customer satisfaction?
- Which regions contribute the highest revenue?
- How can customer retention and operational efficiency be improved?

## Key Insights

- Generated over **20.58M** in revenue from approximately **99K** orders.
- Identified the highest revenue-generating product categories and customer regions.
- Evaluated payment behavior across different payment methods.
- Measured delivery performance and its impact on customer review scores.
- Analyzed repeat customer purchasing patterns and average order value.
- Developed business recommendations to improve operational efficiency and customer retention.


## Dataset

The analysis is based on the **Olist Brazilian E-Commerce Public Dataset**.

The original dataset is publicly available on Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Due to GitHub file size limitations, the original raw datasets are not included in this repository.
